# 3D

> **Status:** experimental (2026-07-23)

## Purpose

The studio's 3D capability — props, rigs, and environment pieces blocked out in Blender and imported
into Studio. Process: [[3d-asset]].

## Standard

glTF source → `.rbxm` runtime. Runtime containers answer to `tgl-asset` — `{CAT}_{SUB}_{Name}.rbxm`,
PascalCase name, **no status tail** (CAT ∈ PRP · RIG · EFX · ENV · LAY · ACC · GUI); source packages
under `3d/` answer to no law — the DCC owns the names ([[0013-assets-by-medium-the-foundry-decides]]).

## Tooling

Blender MCP (the `blender-mcp-craft` skill) for modeling; Roblox Studio MCP for import;
`validate-3d-asset-art.mjs` for the `3d/models/` package.

## Output convention

Source packages in `3d/models/<category>/<slug>/` (the per-asset package — `README · manifest · boards ·
prompts/ · exports/`); DCC working files in `3d/source/blender/` · `3d/source/terrain/`; runtime in
`runtime/roblox/soul-steel/<category>/<domain>/`. **Pattern B**
(Studio upload → `ServerStorage.TrembusGameLibrary`) per
[[0001-reference-the-shared-asset-library-via-external-locations]]; doors per
[[0013-assets-by-medium-the-foundry-decides]].

## Quality bar

Correct scale + origin; greyboxed blockout before detailing; passes `validate-3d-asset-art.mjs` and
`validate_asset_ids.py`.

## Scale & lookdev

- Working scale: **1 Blender unit = 1 stud** (confirmed 2026-07-23 against the Roblox
  stylized-human reference — 6.43 studs, Rthro-class).
- **Two labs, one per pipeline end.** Authoring: `Assets/_tools/blender/lookdev.blend` — link the
  asset's collection into its `review` slot to judge bakes, materials, and scale under controlled
  rigs (three swappable light rigs, calibration references, an HDRI world option). Acceptance: the
  in-Studio Part-Texture-Testing-Lab — the only place that proves how it renders in-engine. Never
  approve an asset from a Blender render alone.
- Shared Blender data (materials, reference rigs, templates): **link, never append** — the
  [[0001-reference-the-shared-asset-library-via-external-locations]] by-reference rule applied
  inside Blender. One shippable asset = one named collection, so it stays linkable.
